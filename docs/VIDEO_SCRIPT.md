# ArrivalGuard video script (4:30)

Structure from BUILD_PROMPT 18.1. Recorded on the live demo (https://arrivalguard.vercel.app) at 1440 px wide, light theme, with the simulation band visible in every shot. Every number spoken or shown comes from the screen or from a file in the repository; nothing is staged or edited into the interface.

**What is simulated, said once at the start and visible throughout:** the family funds, the accounts, the payment provider and Arrival University are synthetic. No real money moves. Prices, exchange rates and arrival times are fixed scenario values.

## Preparation

Opening a workspace ends the sessions of the previous workspace in the same browser, so the scenes use two cookie jars: the normal window and a private window.

1. Normal window: open https://arrivalguard.vercel.app, **For judges**, code `<EVAL_ACCESS_CODE>`, scenario **Base scenario**, **Open the demo**. This is workspace A (scenes 0:00 to 2:50).
2. Private window: open another workspace with **Arrival transfers**. This is workspace B (scene 2:50).
3. Off camera, after recording scene 2:50: in the private window, console, **Start new workspace** with **Base scenario** (workspace C). As Sofía, send "Pay my tuition without touching the arrival reserve. It must arrive within 48 hours." so that a plan waits for Carlos's approval. Scene 3:25 is recorded in workspace C.
4. Keep the browser's developer tools ready (console tab) for scene 3:25, closed until then.
5. If the chat is slow on a take, the same step can be done with **Use structured controls**; say so in the voice-over if it is used.
6. Have `docs/results/RESULTS.md` from the frozen commit open for the last scene.

## Rules for the recording

- Do not cut out a failure or replace a figure. If a take shows an error, record again from the start of the scene; never edit numbers in post-production.
- The 403 in the scene at 3:25 is an HTTP response shown in the developer tools. It is not written to the event log as a security event (the log records security blocks from the chat and from agent tools); what the log shows is that no approval was granted.
- The results scene uses only `docs/results/RESULTS.md`. If that file does not exist at recording time, the scene says that results are in [EVALUATION.md](EVALUATION.md) and shows no numbers.
- Keep the simulation band in frame in every shot of the application.
